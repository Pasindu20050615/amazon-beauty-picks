# Everyday Beauty Picks

Static, crawler-readable product-guide site prepared for GitHub Pages.

- 20 individual product guides, each with a 100-word article body.
- Responsive index and topic-organized product cards.
- Product images are optimized JPEG copies of the supplied Pinterest pin artwork.
- Affiliate disclosures appear beside calls to action and on the About page.
- Per-page title, description, canonical, Open Graph/Twitter metadata, and BlogPosting JSON-LD.
- `sitemap.xml` and `robots.txt` included.

For local preview: `python3 -m http.server 8000` from the repository root, then open `http://localhost:8000/`.
